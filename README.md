# 🍂 Осенняя сказка для тебя

Романтический сайт-квест: вступительный экран, письмо, выбор одного из пяти квестов, выбор даты и финальное подтверждение. Ответ отправляется на сервер и записывается в `data/responses.json`.

## Что нужно установить

- Node.js версии 18 или новее: https://nodejs.org/
- Любой редактор, например Visual Studio Code.

## Запуск на компьютере

1. Распакуй архив в отдельную папку.
2. Открой эту папку в VS Code.
3. Открой терминал VS Code: **Терминал → Создать терминал**.
4. Выполни команду:

   ```bash
   npm install
   ```

5. Затем запусти сайт:

   ```bash
   npm start
   ```

6. Открой в браузере `http://localhost:3000`.

Не открывай `index.html` двойным щелчком: сервер нужен для сохранения ответа.

## Где посмотреть ответ

После того как девушка отправит выбор, открой файл:

`data/responses.json`

В нём появится запись с названием квеста, датой и временем получения. Сервер также выведет короткое сообщение в терминал.

Пример записи:

```json
{
  "id": "пример-идентификатора",
  "questId": "2",
  "quest": "Зазеркалье",
  "date": "2026-10-25",
  "receivedAt": "2026-10-20T12:00:00.000Z"
}
```

Файл ответов не отдаётся посетителям сайта через публичный URL. Не добавляй маршрут, который публично показывает все ответы.

## Музыка

Положи свои аудиофайлы сюда:

- `public/music/main.mp3` — музыка на протяжении сайта.
- `public/music/final.mp3` — музыка для финального экрана.

Файлы не включены в архив: используй музыку, на которую у тебя есть права. Если аудиофайлов пока нет, сайт продолжит работать, просто без музыки. Браузеры могут блокировать автоматическое воспроизведение до первого нажатия — это нормально.

## Изображения квестов

Карточки квестов нарисованы средствами CSS, поэтому отдельные изображения не нужны и не появятся сломанные заглушки. Все стили находятся в `public/style.css`, логика — в `public/script.js`.

## Как отправить сайт девушке

`localhost` доступен только на твоём компьютере. Чтобы сайт открывался у неё, разверни весь проект на Node.js-хостинге, который поддерживает запуск `npm start` и постоянное хранение файлов. После публикации отправь ей публичный HTTPS-адрес.

**Важно:** некоторые серверless-хостинги очищают локальные файлы или используют временную файловую систему. Для такого хостинга вместо `data/responses.json` нужна постоянная база данных. Если хостинг перезапускает приложение, хранилище файлов должно быть постоянным.

## Если что-то не работает

- `npm` не найден — установи Node.js и перезапусти терминал.
- Порт занят — запусти PowerShell с ` $env:PORT=3001; npm start `, затем открой `http://localhost:3001`.
- Ответ не сохранился — проверь сообщения в терминале и наличие права записи в папку `data`.
- Музыка не играет — проверь имена файлов и включи музыку кнопкой внизу справа.
